# Cara Pakai Cepat

Dokumentasi lengkap ada di **[README.md](./README.md)**.

## Ringkasan langkah

1. **Edit teks & data** → `src/data/wedding.ts`
2. **Ganti foto** → `public/photos/` + sesuaikan path di `wedding.ts`
3. **Ganti musik** → `public/music/bgm.mp3` + set path di `wedding.ts`
4. **Ganti warna/tema** → bagian `theme.colors` di `wedding.ts`
5. **Setup Supabase** (ucapan) → lihat bagian "Setup Supabase" di README
6. **Setup Tally** (RSVP) → lihat bagian "Setup Tally" di README
7. **Deploy** → `npm run build` lalu upload `dist/` atau hubungkan ke Vercel
